# 知识卡片 Skill

`make-knowledge-cards` 是一个 Codex 技能，用于把长篇笔记、讲义和读书摘要整理成便于逐条复习的知识卡片，省去手动筛选和合并重复内容的工作。

## 主要功能

- 接收粘贴的文本，或读取本地 Markdown（`.md`、`.markdown`）和 TXT 文件。
- 合并重复内容，每张卡片聚焦一个知识点。通常生成 5–8 张，材料不足时按实际数量输出。
- 在回复中以 Markdown 输出卡片。每张包含标题、核心知识、简明解释，以及原文中的例子或一道自测题。卡片以提供的材料为依据。
- 网页或 PDF 内容需先整理为受支持的文本。输出格式为 Markdown 卡片，暂不支持 Anki 导出或图形界面。

## 安装方法

在 Codex 中打开本项目，即可通过技能文件路径调用，无需安装额外依赖。若希望通过 `$make-knowledge-cards` 选择技能，可将整个 `skills/make-knowledge-cards` 目录复制到项目的 `.agents/skills/` 中，使入口位于 `.agents/skills/make-knowledge-cards/SKILL.md`，然后重新打开 Codex 会话。

## 使用方法

技能出现在选择器中时，用 `$make-knowledge-cards` 调用。直接使用项目内的技能时，在提示中写明「请使用 `skills/make-knowledge-cards/SKILL.md`」。

- **粘贴文本**：请使用技能把以下内容整理为知识卡片。随后粘贴原文。
- **本地文件**：请使用技能把 `notes.md` 整理为知识卡片。文件不在项目目录时，提供完整路径。

## 输入与输出示例

**输入**

> 请使用 `skills/make-knowledge-cards/SKILL.md` 把下面的笔记整理成知识卡片。
>
> 二分查找适用于已排序的数组。每次比较目标值与中间元素，排除不可能包含目标值的一半。

**输出**

### 二分查找

- **核心知识**：二分查找通过反复排除一半候选范围来定位目标。
- **简明解释**：数组需先排序。比较目标值与中间元素，即可判断哪一半不可能包含目标值。
- **自测问题**：二分查找对数组有什么要求？每次比较后可以排除多少候选范围？
